About

CurrencyFlow is a small project built with HTML, CSS and vanilla JavaScript. Rates come from the free fawazahmed0 currency API and flags from flagsapi.com. Nothing you type is stored or sent anywhere except the request for a currency's rates. Rates are for information only and may differ from bank rates.

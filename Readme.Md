# 💱 Currency Converter

A web-based currency converter built using HTML, CSS, and JavaScript. It allows users to convert amounts between different currencies using exchange rates retrieved from an external API.

## Features
- Convert between multiple currencies.
- Dynamic country flags.
- Exchange rates fetched using an API.
- Simple and user-friendly interface.
- Input validation and error handling.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Currency Exchange API
- Flags API
- Font Awesome

## How to Run
1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Run `index.html` using the Live Server extension.
4. Enter an amount and select the source and target currencies.
5. Click **Get Exchange Rate** to see the converted amount.
